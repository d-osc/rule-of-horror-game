# ตอนที่ 2 — กฎในการไปเยี่ยมบ้านย่านุ่น

อ้างอิง [หลอนตามสั่ง EP.90 โดย nuenglc](https://www.youtube.com/watch?v=YIDy9bZH6Ko) คำอธิบายคลิปให้เครดิตเรื่องแก่ K.รพีภัณฑ์ บันทึกนี้เรียบเรียงจากคำบรรยายไทยอัตโนมัติ เวลาที่ระบุเป็นเวลาในคลิป ส่วนเวลานาฬิกาในเรื่องระบุแยกไว้

| ช่วงคลิป | เหตุการณ์ที่ต้องรักษา |
| --- | --- |
| ก่อนออกเดินทาง–07:15 | ย่านุ่นบอกข้อห้ามทางโทรศัพท์ หลานกับลุงเตรียมเดินทางไปอ่างทอง ลุงจดกฎไว้ แม้ตอนแรกจะคิดว่าย่าหลอกให้กลัว |
| 08:14–10:52 | ขับขึ้นเขาตอนฟ้ามืด เจอศาลไม้เก่าตรงโค้งและบีบแตรตามคำเตือน กลิ่นเหม็นเข้ารถแต่ไม่เปิดกระจก ต่อมาพบชายถอดเสื้อนุ่งผ้าขาวม้าข้างถนน และพบชายคนเดิมอีกครั้งโดยไม่ทัก |
| 10:52–13:28 | ที่ทางแยก ลุงจำทางไม่ได้ หลานโทรถามย่าและเลี้ยวขวาตามคำบอก ออกจากเขาราว 02:55 น. แล้วพักในปั๊ม ลุงเผลอแผ่เมตตาแต่คืนนั้นที่ปั๊มผ่านไปโดยไม่มีเหตุ เช้าจึงออกเดินทางต่อและเจอครอบครัว |
| 13:50–16:08 | ย่าขอให้ลุงไปเฝ้าเล้าเป็ดไก่กลางนา หลังไก่แถวนั้นตายปริศนา หลานช่วยขนของแล้วกลับไปนอนกับย่า ลุงพบกระดาษกฎพับเหน็บที่คานใต้หลังคาสังกะสี |
| 16:36–19:10 | อ่านกฎกระท่อมทั้งสองด้าน กระดาษเตือนเรื่องปอบช่วง 21:00 น. ช่วงพักราว 22:00–23:00 น. และให้ออกก่อนเที่ยงคืนเพื่อไปหาชายแก่ที่คันนาพร้อมห่อยาเส้น ด้านหลังเป็นข้อปฏิบัติเพิ่มเติม ย่ามเป็นของสำคัญ |
| 19:21–22:27 | ลุงตรวจย่ามและตะเกียง ได้ยินเสียงจากเล้าไก่ เห็นร่างหญิงชราที่คิดว่าเป็นปอบ และพยายามรับมือ ปืนที่พกมาขัดข้อง เมื่อกลับไปดูร่างนั้นหายแล้ว ช่วง 22:00 น. ลุงกลับขึ้นกระท่อม |
| 22:30–24:42 | ลุงหลับแทนที่จะออกก่อนเที่ยงคืน ตื่นมาเห็นชายแก่และออกไปตามคันนา มือปริศนาคว้าขา ชายแก่เข้าช่วย ลุงยื่นห่อยาเส้นให้และขอไปพักบ้านชายแก่จนเช้า เหตุการณ์สงบลง |
| 25:01–27:07 | เรื่องเล่าย้อนมาจากความทรงจำหลายปีก่อน ภายหลังชายแก่บอกว่าสิ่งที่เล่นงานลุงเป็นบริวารของปอบ กระท่อมเคยมีคนแปลกหน้ามาพักแล้วหายตัวไป ชายแก่ยืนยันว่าเขาไม่รู้ที่มาของกฎ |

สำหรับการนำไปทำเกม ให้ผู้เล่นอยู่กับหลานในช่วงเดินทางและสลับไปอยู่กับลุงเมื่อเริ่มเฝ้ากระท่อม ลำดับในฉบับเนื้อเรื่องหลักให้แยก **คำเตือนในกฎ** ออกจาก **สิ่งที่ลุงทำจริง** โดยเฉพาะการหลับเลยเวลาที่ควรออกและการไปพักบ้านชายแก่ จังหวะโต้ตอบและการย่นเวลาเป็นการออกแบบเกม ส่วนบทสนทนาใช้การเรียบเรียงใหม่

ก่อนล็อกบท ให้ฟังเสียงต้นฉบับซ้ำช่วงคำเตือนก่อนขึ้นเขาและกฎด้านหลังกระดาษ คำบรรยายอัตโนมัติอ่านคำบางช่วงเพี้ยน จึงยังไม่ควรยืนยันถ้อยคำ จำนวนข้อย่อย หรือรายละเอียดที่ฟังไม่ชัดว่าแม่นยำ 100%
