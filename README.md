## เริ่มเล่น

ต้องมี Node.js 22.12+ หรือเวอร์ชันที่ Vite 8 รองรับ

```powershell
npm install
npm run dev
```

เปิด http://127.0.0.1:5188 คลิกเช็คอิน อ่านกฎ แล้วเริ่มจากเติมอ่างให้เต็ม

กดปุ่ม **ตอนที่ 2** หรือปัดไปทางขวาบนมือถือแนวนอนเพื่อดูฉากตัวอย่างบ้านย่านุ่น

| ปุ่ม | การใช้งาน |
| --- | --- |
| W A S D / ลูกศร | เดิน |
| เมาส์ | มองรอบตัว คลิกฉากเพื่อล็อกเมาส์ หรือกดค้างแล้วลากหากเบราว์เซอร์ไม่รองรับ |
| E | ใช้งานวัตถุที่เล็ง / ล้างตาเมื่ออยู่ใต้ฝักบัว |
| C | หลับตา / ลืมตา |
| R | อ่านกฎซ้ำ เกมจะพักขณะอ่าน |
| Esc | หยุดเกม / ปลดเมาส์ |

มือถือและแท็บเล็ตใช้จอยซ้าย ลากฉากเพื่อมอง ปุ่มใช้/เก็บ หลับตา และอ่านกฎด้านขวา ควรใช้หูฟัง ปรับความไวเมาส์และลดการเคลื่อนไหวได้จากหน้าพักเกม

## Build และตรวจสอบ

```powershell
npm test
npm run build
npm run preview
```

Build อยู่ใน `dist/` เป็นเว็บ static เปิดผ่าน HTTP ไม่ใช่ file:// หากวางใน subpath ให้กำหนด `base` ใน vite.config.ts ให้ตรง host ก่อน build การทดสอบใช้ Chromium ผ่าน Playwright ติดตั้งด้วย `npx playwright install --no-shell chromium` หากยังไม่มี

Unit tests ตรวจทั้งเก้ากฎ เส้นทางชนะ เงื่อนไขแพ้ การพัก และรีเซ็ต Browser tests ใช้ E/C จริงในการผ่านกฎ โดยใช้ QA hooks จัดตำแหน่ง/เร่งเวลาระหว่างเหตุการณ์ และตรวจ input เดินจริงแยกต่างหาก QA hooks เปิดเฉพาะ dev หรือ URL `?qa=1` ไม่ได้เปิดในหน้า production ปกติ

## Codex integrations

ติดตั้งสกิล `threejs-game-*` รวม 9 ตัวไว้ที่ `C:\Users\ondev\.codex\skills` และเพิ่ม global MCP `threejsresources` และ `blender` ในการตั้งค่า Codex แล้ว สกิลใหม่พร้อมให้ค้นพบในเทิร์นถัดไป หาก client ยังไม่แสดง MCP tools ให้โหลด Codex ใหม่

Blender bridge ใช้ addon ของ [MCP for Blender](https://github.com/ahujasid/mcp-for-blender) กับ `uvx mcp-for-blender` และ addon listener localhost:9876 สคริปต์ในโปรเจกต์เปิด Blender แยกต่างหากเพื่อรักษาฉากเดิมของผู้ใช้

การทดสอบมือถือใช้ Chromium จำลองหน้าจอสัมผัส เสียงประกอบสังเคราะห์และมีข้อความบรรยายเหตุการณ์ภาษาไทย

งานสังเคราะห์เสียงทำผ่าน Web Worker และส่งข้อมูลเสียงกลับด้วย transferable buffers
มือถือใช้ความละเอียดเรนเดอร์สูงสุด DPR 1 และอัปเดตข้อความ HUD 10 ครั้งต่อวินาที
